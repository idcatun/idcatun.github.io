# Grant Quant — Portfolio

Personal portfolio website built from scratch with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

Live at: **[idcatun.github.io](https://idcatun.github.io)**

## Sections

- **About** — Background, education, and interests
- **Skills** — Languages, security tools, and platforms
- **Projects** — Rivals Scout, Password Manager, Ethical Keylogger
- **Resume** — Education and work experience, with PDF download
- **Contact** — Email, GitHub, LinkedIn, and contact form

## Stack

- HTML / CSS / JavaScript
- Fonts: [Syne](https://fonts.google.com/specimen/Syne), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), [DM Sans](https://fonts.google.com/specimen/DM+Sans) via Google Fonts
- Hosted on GitHub Pages
