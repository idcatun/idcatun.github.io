Rivals Scout

An async scouting tool for collegiate Marvel Rivals matches that aggregates opponent player stats (rank, peak rank, hero performance) via Playwright browser automation, with automatic fallback between sources for private profiles. Features an OCR pipeline using OpenCV and Tesseract to extract player names directly from game screenshots.

Password Manager

A secure password manager with both command-line and graphical interfaces built in Ruby with GTK3. Uses AES-256 encryption for credential storage with cryptographic keys derived from a master password via SHA-256 hashing, ensuring strong resistance against brute-force attacks.

Ruby GTK3 AES-256 SHA-256
